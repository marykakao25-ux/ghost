# Карта ввода

## Текущее состояние

В `project.godot` **нет секции `[input]`**. В `README.md` упоминаются действия `UI_UP`, `UI_DOWN`,
`UI_LEFT`, `UI_RIGHT`, но это встроенные действия интерфейса Godot: они управляют фокусом меню и могут
меняться движком. **Для геймплея их использовать нельзя.**

Действия добавляются задачей **T-0002** (правка `project.godot`). До её выполнения код не должен
жёстко требовать этих действий — проверяйте `InputMap.has_action()` для новых сцен.

## Согласованный набор действий (T-0002)

| Действие | Назначение | Клавиши по умолчанию |
|---|---|---|
| `move_left` | движение влево | A, ← |
| `move_right` | движение вправо | D, → |
| `move_up` | вверх (ворон) | W, ↑ |
| `move_down` | вниз (ворон) | S, ↓ |
| `jump` | прыжок (кот, пёс) | Space |
| `crawl` | подползание (кот) | Ctrl, S |
| `shapeshift` | следующая форма | Q |
| `shapeshift_cat` | форма кота | 1 |
| `shapeshift_dog` | форма пса | 2 |
| `shapeshift_bird` | форма ворона | 3 |
| `pause` | пауза | Esc |

## Как добавить действие

1. Только через `infra`-задачу с `paths: [project.godot]`.
2. В редакторе: Project → Project Settings → Input Map.
3. После сохранения — обновить эту таблицу в том же PR.
4. Проверить, что имя действия не совпадает с встроенным (`ui_*`).

## Правила использования в коде

```gdscript
var direction: float = Input.get_axis("move_left", "move_right")
if Input.is_action_just_pressed("jump") and player.is_on_floor():
	player.velocity.y = JUMP_VELOCITY
```

* Использовать `get_axis`/`is_action_just_pressed`, а не прямые коды клавиш (`KEY_A`, `MOUSE_BUTTON_*`).
* Мёртвая зона для аналоговых осей — 0.2.
* Не переопределять действия во время игры без задачи (кроме меню настроек, если оно появится).
