# GEMINI.md

Все инструкции для ИИ-агентов в этом репозитории находятся в одном файле:

**→ [`AGENTS.md`](AGENTS.md)**

Прочитайте его целиком перед любой командой. Кратко, если файл ещё не открыт:

1. Работа начинается с `pwsh -File scripts/agent/status.ps1`.
2. Задача захватывается **только** через `pwsh -File scripts/agent/claim.ps1 -Task T-XXXX -Owner <имя>`.
3. Работать только в ветке `task/T-XXXX-*` и только с файлами из `paths` задачи.
4. Завершение — `release.ps1` + `verify.ps1` + PR с названием `[T-XXXX] ...`.
5. Код в `main` напрямую не коммитится.
