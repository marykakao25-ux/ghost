## Контекст

`MovementBird._update_animation()` выбирает `bird_fly` только по вертикальной скорости.
При быстром горизонтальном движении остаётся `bird_idle`, из-за чего ворона визуально летит
в неподходящей позе.

## Шаги

1. Выбирать анимацию полёта по полной скорости персонажа.
2. Сохранять idle только при почти полном отсутствии движения.
3. Проверить горизонтальный, вертикальный и диагональный полёт.

## Acceptance criteria

- [ ] При горизонтальном, вертикальном и диагональном движении проигрывается `bird_fly`
- [ ] При остановке проигрывается `bird_idle`
- [ ] Направление спрайта по горизонтали не сломано
- [ ] Проект открывается в Godot 4.7 без ошибок парсинга и без новых предупреждений

## Проверка
